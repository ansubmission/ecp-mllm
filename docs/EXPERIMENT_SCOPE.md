# Experiment scope

The retained experiment set covers four connected regimes:

- event-centric inference on weak-signal sonar streams,
- event-centric inference on weak-signal thermal streams,
- compact local evaluation on structured event windows,
- lightweight low-rank adaptation for compact models.

The benchmark configs kept in `config/prompt_dev` are the main entry points for
the retained sonar and thermal slices. The corresponding code paths are
summarized in `CODE_ORIENTATION.md`, and representative execution patterns are
listed in `RUNNING_EXPERIMENTS.md`.
