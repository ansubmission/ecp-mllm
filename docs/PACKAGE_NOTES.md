# Package notes

This repository is organized around the event-centric stream experiments. The
main library lives under `src/ecp_mllm`, benchmark and result manifests live
under `config`, and the compact-model wrappers live under `runtime`.

The code is easiest to read in three passes:

1. `docs/CODE_ORIENTATION.md` for the main modules,
2. `docs/EXPERIMENT_SCOPE.md` for the retained benchmark slices,
3. `docs/RUNNING_EXPERIMENTS.md` for representative entry points.
